# Front-End Learning (FE_Learning) 🚀

Chào mừng bạn đến với kho lưu trữ học tập và thực hành lập trình **Front-End**!

---

## 📌 Giới thiệu

Kho lưu trữ này được xây dựng nhằm mục đích:
- Lưu trữ các bài giảng, ghi chú và tài liệu học tập Front-End.
- Thực hành các bài tập từ cơ bản đến nâng cao (HTML, CSS, JavaScript, Frameworks,...).
- Xây dựng các dự án mẫu (mini-projects, landing pages, web applications).

---

## 🗺️ Lộ trình học tập (Roadmap)

1. **Giai đoạn 1: Nền tảng Web Cơ bản**
   - **HTML5**: Thẻ cấu trúc ngữ nghĩa (Semantic HTML), Form, Table, SEO cơ bản, Accessibility.
   - **CSS3**: Box Model, Flexbox, CSS Grid, Responsive Design (Media Queries), Animation & Transition.

2. **Giai đoạn 2: Lập trình JavaScript Hiện đại (ES6+)**
   - Cú pháp cơ bản, Kiểu dữ liệu, Hàm, Vòng lặp.
   - DOM Manipulation & Event Handling.
   - ES6+ (Arrow functions, Destructuring, Spread/Rest, Modules, Promises, Async/Await).
   - Fetch API / Axios & làm việc với RESTful API.

3. **Giai đoạn 3: UI & CSS Tools**
   - CSS Preprocessors: SASS/SCSS.
   - CSS Frameworks / Utilities: Tailwind CSS, Bootstrap.

4. **Giai đoạn 4: Single Page Application (SPA)**
   - Framework/Library: ReactJS (hoặc VueJS).
   - State Management (Redux Toolkit / Zustand / Context API).
   - Routing, API Integration, Performance Optimization.

5. **Giai đoạn 5: Build Tools & Quản lý Mã nguồn**
   - Git & GitHub: Quản lý phiên bản, làm việc nhóm.
   - Package Managers: npm, yarn, pnpm.
   - Bundlers: Vite, Webpack.
